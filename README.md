# ⚙️ Управление ресурсами в ДИВС

Симулятор динамического распределения вычислительных ресурсов
в распределённой информационно-вычислительной системе.

## Структура проекта

```
resource_manager/
├── app.py                   # Главное Streamlit-приложение
├── requirements.txt
└── src/
    ├── data_generator.py    # 10 генераторов данных (магазинов)
    ├── resource_manager.py  # Алгоритм управления ресурсами
    └── task_factory.py      # Фабрика вычислительных задач
```

## Быстрый старт

```bash
# 1. Установить зависимости
pip install -r requirements.txt

# 2. Запустить приложение
streamlit run app.py
```

Приложение откроется в браузере по адресу http://localhost:8501

## Алгоритм приоритизации

```
priority(t) = efficiency(t) × feasibility(t) × urgency(t) + age_bonus(t)

efficiency(t) = expected_effect(t) / cost_weight(t)
feasibility(t) = 1.0 (если ресурсов хватает) | 0.1 (если нет)
urgency(t)    = f(задержка сети, случайный шум)
age_bonus(t)  = log(1 + возраст × 10) × 0.05  # против «голодания»
```
